\section*{Highlights}
\textbf{Beyond Top-K: A Typed Operator Suite for Answer-Geometry Mismatches in Knowledge Graph Question Answering} --- submission to \emph{Knowledge-Based Systems}\\[4pt]
\begin{itemize}[leftmargin=1.2em,nosep]
\item Top-$K$ GraphRAG fails on enumeration, intersection and complement geometries
\item We derive six typed retrieval operators, one per answer-geometry class
\item An oracle ablation localizes the full $+35.9$ pp gain to the operators
\item RadarKG-QA-499, a bilingual answer-geometry-mismatch benchmark, is released
\item Deployable at \$0.00041 per query for industrial knowledge-based QA
\end{itemize}
