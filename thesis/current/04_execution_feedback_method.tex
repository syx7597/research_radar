\chapter{小模型知识图谱问答的恢复轨迹监督方法}
\label{chap:execution-feedback}

\section{研究问题与总体思路}

知识图谱问答将自然语言问题转化为实体查找、关系遍历、属性筛选和结果比较等操作。分步查询模型在每次操作后读取执行结果，再决定下一步动作，因此能够利用中间实体集合、属性值和执行反馈完成多步求解。这种交互方式对模型提出了两项要求：一是生成与问题相关的查询操作，二是在已有执行历史下维持有效的后续求解过程。

常规监督微调主要使用正确参考轨迹。模型在训练中见到的是沿参考路径产生的上下文，自由运行时则需要处理自身动作形成的状态。例如，多执行一次无关查询会改变中间结果编号，错误筛选可能产生空集合，无效依赖还可能引发连续调用失败。即使模型已经掌握正确程序的生成方式，也可能因这些历史差异而中断求解。本文据此研究如何将模型自身产生的偏离状态转化为有效训练样本，提高小模型在固定调用预算下的问答成功率。

本章提出基于真实执行历史的恢复轨迹监督方法。首先，让初始分步模型在训练问题上自由运行，采集失败回合；其次，定位失败轨迹与参考程序的首次分歧，保留共同成功前缀以及真实分歧动作和反馈；最后，根据当前中间结果重新映射参考后缀的依赖，执行验证后将其作为监督目标。训练时，模型读取偏离历史，并学习在该历史下继续生成可执行的求解动作。

该方法由三个相互衔接的环节组成：\textbf{真实偏离状态选择、依赖重映射的后缀构造和目标位置控制}。真实轨迹提供模型实际遇到的状态，依赖重映射使参考求解路径适应当前环境，监督掩码则将学习目标集中于后续动作。为评价这一训练构造，本文建立普通续训组 A 与恢复续训组 C，使两组共享初始模型、问题、记录次序和监督 token 预算。第\ref{chap:public-experiments}章通过配对实验分析问答效果、执行状态与推理成本。

\section{执行环境与任务定义}

\subsection{分步查询与执行状态}

设知识图谱为 $G$，问题为 $q$，第 $t$ 步执行前的状态为 $s_t$，模型可见的交互历史为 $h_t$。语言模型根据问题和历史生成动作 $a_t$，执行器返回观察 $o_t$ 并更新状态：
\begin{align}
  a_t &\sim \pi_\theta(\,\cdot\mid q,h_t), \\
  (s_{t+1},o_t) &= \mathcal{E}(G,s_t,a_t), \\
  h_{t+1} &= h_t\mathbin{\Vert}(a_t,o_t).
\end{align}
其中 $\mathcal{E}$ 为固定执行器，$\Vert$ 表示历史追加。状态包括中间结果、执行事件、调用次数和回合终止标志。中间结果通过句柄引用，每个句柄对应一次成功操作得到的实体集合、属性值或比较结果。

普通查询动作写为
\begin{equation}
  a_t=(f_t,\ell_t,D_t),
\end{equation}
其中 $f_t$ 为操作函数，$\ell_t$ 为关系、属性、数值等字面参数，$D_t$ 为依赖句柄列表。结束动作指定答案句柄，将已有结果提交为最终答案。观察包含执行成功标志、结果内容或失败说明。执行成功表示操作满足接口要求；问题相关性则由查询路径及最终答案共同体现。空集合和空值也是执行器可能返回的合法结果。

自由运行轨迹记为 $\tau=(a_1,o_1,\ldots,a_T,o_T)$。模型在预算内提交答案后，使用任务答案比较函数计算正确性；耗尽预算或未提交答案的回合计为未完成。推理阶段的模型输入由问题、工具说明及已产生的执行历史组成。

\subsection{参考监督与恢复目标}

训练数据包含问题 $q$、参考程序 $P^*$ 和参考答案 $y^*$。执行参考程序可得到参考动作序列 $a^*_{1:K}$ 及其观察，本文将最终答案提交操作一并计入该序列。参考程序在离线阶段用于构造训练目标，训练完成后的模型通过自身生成的动作完成求解。

本文将恢复定义为：\textbf{在保留真实偏离历史的条件下，利用已有中间结果继续执行并提交正确答案。}在当前查询环境中，恢复可以表现为跳过无关结果、重新选择有效依赖或结束无效调用链条。相应训练目标是后续可执行动作，而非额外的自然语言反思说明。这一定义使数据构造、损失计算与最终问答评价保持一致。

\section{真实失败轨迹的配对构造}

\subsection{共同前缀与分歧状态选择}

对每个训练问题，使用初始分步模型 I 生成自由轨迹 $\hat\tau$。构造器先重新执行记录中的动作，比较实际观察、执行事件和提交答案，保留记录一致且最终未正确作答的轨迹。同时执行参考程序，确认其能够生成参考答案。

设自由动作序列为 $\hat a_{1:T}$，从起点开始比较其工具名称、参数和执行成功状态，确定与参考程序一致的最长共同成功前缀，长度为 $k$。样本要求 $k\geq1$，并且在该前缀之后存在实际分歧动作 $\hat a_{k+1}$。共同前缀提供一组可用的中间结果，首次分歧则提供模型真实产生的额外状态。

这里的分歧按参考路径定位，其作用是确定恢复监督的起点。参考程序之外也可能存在正确求解路径，因此样本选择同时结合完整自由回合的失败结果和后缀的实际可执行性。该策略直接利用模型运行记录构造恢复上下文，无需为每个中间动作增加语义错误标注。

\subsection{普通续训与恢复续训序列}

将共同前缀对应的交互历史记为 $H_k$。普通续训组 A 与恢复续训组 C 的配对序列分别为
\begin{align}
  x^A &= (q,H_k,a^*_{k+1:K},\mathrm{Done}), \\
  x^C &= (q,H_k,\hat a_{k+1},\hat o_{k+1},
                 \rho(a^*_{k+1:K}),\mathrm{Done}).
\end{align}
式中各后缀动作之间均包含执行器实际返回的观察，为简洁未逐一展开；$\rho$ 表示依赖句柄重映射；$\mathrm{Done}$ 是结束训练序列的助手文本。A 从共同前缀直接沿参考路径继续，C 则先保留一次实际分歧及其反馈，再沿重新映射后的参考路径继续。

两组后缀具有相同的操作函数、字面参数和依赖图。由于分歧动作可能新增结果，C 中后续动作的句柄编号需要与实际状态对应。配对构造因此同时处理动作目标和执行环境，使相同的求解逻辑能够放入两种历史上下文。

\subsection{依赖句柄重映射}

设映射 $m(i)$ 表示参考程序第 $i$ 个中间结果在当前回合中的实际句柄。重放共同前缀时建立初始映射；执行参考后缀第 $i$ 个动作时，将依赖列表 $D_i^*$ 转换为
\begin{equation}
  \rho(a_i^*)=
  \left(f_i^*,\ell_i^*,[m(j):j\in D_i^*]\right).
\end{equation}
执行成功并得到实际句柄 $u$ 后，令 $m(i)=u$。结束操作使用同一映射取得答案句柄。若分歧动作被执行器拒绝，则按实际结果处理，已有句柄编号保持原状。

这一映射保留参考求解路径的依赖关系。例如，额外查询产生了一个无关结果时，后续动作仍可以使用分歧之前已经取得的有效实体；当后续参考动作产生新结果时，后续依赖再转向新句柄。该过程将参考程序的逻辑依赖与当前回合的物理编号对应起来。

构造在只读、确定性查询环境中进行，并使用追加式中间结果管理。其成立条件为：共同前缀可重放、已有结果保持可引用、参考依赖映射完整，以及插入分歧后仍有足够的调用预算。构造器分别执行 A/C 后缀，将实际观察中的句柄规范到对应编号后逐项比较，并核验最终答案。由此得到同时满足执行约束与答案要求的训练配对。

\subsection{构造算法}

图\ref{fig:recovery-construction}给出整体流程。对一个问题的配对构造可表述为以下算法，其中 $B$ 为回合调用上限。
\begin{enumerate}
\item \textbf{输入与回放。}输入问题 $q$、参考程序 $P^*$、参考答案 $y^*$ 和自由轨迹 $\hat\tau$。回放自由轨迹并检查记录一致性，筛选最终失败的回合；执行参考程序并核验参考答案。
\item \textbf{定位恢复起点。}确定最长共同成功前缀 $k$，要求 $k\geq1$，并取得其后的实际分歧动作及观察。缺少恢复起点的轨迹记录原因后结束处理。
\item \textbf{建立配对状态。}为 A、C 分别创建回合并重放共同前缀，建立参考结果到实际句柄的映射 $m$。C 继续执行真实分歧动作，保存其观察与状态。
\item \textbf{构造可执行后缀。}检查当前回合仍可执行且调用预算充足。逐个映射参考后缀的依赖并执行，核验对应观察，更新映射 $m$。
\item \textbf{保存监督样本。}通过映射后的答案句柄提交结果，答案核验通过后保存配对。设置前缀、分歧和工具观察的监督掩码为零，后缀助手动作及结束文本为一。
\end{enumerate}

每项执行检查均使用原执行器，未通过的样本记录具体原因。因而配对数据既保留了自由运行上下文，也具有可重复执行的目标路径。

\subsection{配对数据构成}

初始模型共生成 $5\,000$ 条训练自由轨迹，其中 $4\,998$ 条通过回放核验，包含 $4\,339$ 条正确轨迹和 $659$ 条失败轨迹。构造器最终获得 $418$ 个恢复配对，占全部训练问题的 $8.36\%$，占回放一致的失败轨迹约 $63.43\%$。其余轨迹中，$240$ 条缺少共同成功前缀，$2$ 条原始回放记录不一致，$1$ 条参考答案核验未通过。

在 $418$ 个配对中，$414$ 个分歧动作能够执行，$4$ 个被执行器拒绝。因此，恢复语料的主要内容是可执行分歧状态之后的继续求解，覆盖无关操作、空结果和依赖编号变化等情形。共同前缀为这些状态提供已经取得的有效结果，参考后缀则提供可以到达正确答案的监督路径。

\section{监督掩码与训练预算匹配}

\subsection{后缀动作监督}

将序列表示为 $x=(x_1,\ldots,x_L)$，令 $m_j\in\{0,1\}$ 表示第 $j$ 个 token 是否参与损失计算。问题提示、共同前缀、真实分歧动作及所有工具观察的掩码为零；参考后缀中的助手动作和结束文本初始设为一。模型仍读取完整历史，因此分歧和观察作为条件影响后续生成，而监督梯度直接作用于后缀目标。

使用带掩码的因果语言建模目标：
\begin{equation}
  \mathcal{L}_{\mathcal B}(\theta)
   =-\frac{1}{\sum_{x\in\mathcal B}\sum_j m_j}
     \sum_{x\in\mathcal B}\sum_j
       m_j\log p_\theta(x_j\mid x_{<j}),
\end{equation}
其中 $\mathcal B$ 表示参与相应优化步骤的训练记录，批内归一化及梯度累计由固定版本的 Trainer 完成。A/C 的普通成功轨迹部分完全相同，配对后缀部分则分别以共同前缀和含分歧前缀为条件进行学习。

\subsection{逐记录目标数量控制}

为在相同监督量下比较两组，将训练成功轨迹一个遍历所含的 $788\,534$ 个监督 token 设为续训总预算。一半用于普通成功轨迹，一半用于配对后缀，各为 $394\,267$。普通轨迹用于保持已有查询能力，配对部分用于比较不同执行历史下的后续动作监督。

对第 $i$ 个配对记录，设 A/C 原有监督 token 数为 $n_i^A,n_i^C$，该部分剩余预算为 $B_{\mathrm{remain}}$，其共同目标上限为
\begin{equation}
  b_i=\min\{n_i^A,n_i^C,B_{\mathrm{remain}}\}.
\end{equation}
按固定记录顺序保留前 $b_i$ 个监督 token，超出部分从尾部屏蔽，完整输入上下文继续保留。两组使用同一语料构造种子，共享问题顺序、记录次数和逐记录监督数量。

\section{模型训练与推理流程}

\subsection{参数高效训练}

实验采用 Qwen2.5-3B-Instruct\cite{qwen2024qwen25} 作为基础模型，使用 LoRA\cite{hu2022lora} 进行参数高效微调。首先在通过参考回放的成功分步轨迹上训练两个遍历，得到初始模型 I。随后固定 I，采集自由轨迹并构造上述配对语料，分别续训得到 A 和 C。

LoRA 秩为 $16$，缩放参数为 $32$，dropout 为 $0.05$，作用于实现指定的全部线性层。A/C 使用 AdamW，学习率均为 $10^{-4}$，每设备批大小为 $2$，梯度累计步数为 $8$，在配对续训语料上训练一个遍历。训练采用 BF16、梯度检查点和 SDPA 注意力实现，上下文长度上限为 $8\,192$。

配对续训使用 $20261003$、$20261004$ 两个随机种子。两次实验共享初始模型 I 和训练语料，考察续训随机性对方法效果的影响。语料构造、推理和 Python 哈希种子固定为 $20261003$。主要训练设置汇总于表\ref{tab:method-settings}。

\subsection{自由运行评价}

推理时，模型从问题开始逐步生成操作，执行器返回原始反馈，直至提交答案或达到预算。A/C 采用相同提示、工具接口、解码设置和停止规则。每题最多进行 $24$ 次工具调用，总生成上限为 $2\,048$ 个 token，单轮生成上限为 $192$。这些限制共同控制一次问答回合的运行范围。

系统同时记录调用次数、无效调用、完成状态以及输入和生成 token。输入成本按每轮完整提示累计，包括重复出现的历史；生成部分包含 EOS。该记录方式能够呈现分步查询中的上下文重复开销，并用于比较恢复训练前后的执行效率。

\section{本章小结}

本章构建了基于真实执行历史的恢复轨迹监督方法。通过共同前缀定位、实际分歧保留、依赖句柄重映射和后缀回放，将训练模型的失败回合转化为可执行的后续监督。监督掩码使模型在读取偏离状态的同时学习后续求解动作，逐记录 token 匹配则为普通续训与恢复续训建立统一比较基础。

该方案利用有参考程序、可确定性回放和中间结果可持续引用的查询环境，形成 $418$ 个真实恢复配对及相应训练语料。下一章以公开知识图谱问答数据评价这一训练构造的整体效果，并结合执行状态、推理成本和扩展试验分析其行为特征。
