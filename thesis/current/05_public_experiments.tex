\chapter{公开知识图谱问答实验与结果分析}
\label{chap:public-experiments}

\section{实验设计}

本章在公开知识图谱问答数据上评价恢复轨迹监督方法。实验以普通配对续训为主要对照，依次分析三个问题：恢复轨迹训练能否提高最终问答准确率；新增正确答案与执行完成状态之间具有怎样的关系；方法在推理成本、不同问题类型和短程强化学习扩展中表现如何。主要效果由固定的项目留出集给出，开发集用于配对复现和扩展试验。

\subsection{数据集与划分}

实验使用 KQA Pro\cite{cao2022kqapro} 及其知识库执行环境。该数据集提供自然语言问题、参考程序和答案，支持实体查询、关系遍历、集合运算、比较及限定条件查询等操作。参考程序为本研究提供了可执行监督，使训练轨迹构造与最终问答评价能够在同一环境中完成。

本文从官方训练数据中使用 $5\,000$ 道训练题、$500$ 道开发题和 $2\,000$ 道项目留出题。训练和开发部分沿用固定划分；新增留出部分排除此前已使用的全部 $8\,500$ 个历史问题分组。分组由完全相同问题或完全相同程序的连通关系形成，并排除与官方验证集完全重复的问题或程序分组。三部分之间完全相同问题和程序的重叠数均为零。

项目留出集用于评价方法在本项目未使用问题上的效果。在读取其答案评分前，固定五个模型、原始反馈模式、解码配置、主统计量、成本定义及问题分组。五路生成完成后，统一回放四组分步轨迹并重新执行程序基线，共 $10\,000$ 条记录的执行结果与原记录一致，随后进行答案评分。该流程使生成、执行复核和结果统计使用相同的固定输入与规则。

\subsection{对照模型与训练关系}

实验使用同一基础模型构建以下模型组。
\begin{description}
  \item[P：一次性程序生成。] 模型一次输出完整查询程序，再由执行器统一执行。在通过参考回放的训练问题上训练三个遍历，用于比较一次性生成与分步交互两种问答方式。
  \item[I：初始分步模型。] 模型基于成功的分步执行轨迹监督训练两个遍历，用于采集自由运行历史及初始化后续模型。
  \item[A：普通配对续训。] 从 I 出发，以普通成功轨迹和共同前缀后的参考后缀续训，作为主要方法对照。
  \item[C：恢复轨迹续训。] 从相同的 I 出发，将真实分歧及其反馈放入配对上下文，再对可执行参考后缀进行监督，普通轨迹及监督预算与 A 匹配。
  \item[B、D：强化学习扩展。] 分别从第一续训种子的 A、C 出发，执行相同规模的短程 GRPO 训练，在开发集分析增量效果。
\end{description}

A/C 的对比用于评价恢复轨迹构造的整体作用。两组共享问题、记录顺序、重复次数和逐记录监督 token，模型输入的区别来自实际分歧历史及其对应的依赖编号。P 提供另一种推理方式的效果与成本参照。两组续训种子分别为 $20261003$ 和 $20261004$，以下用下标 $1$、$2$ 表示。项目留出集统一评价 P、$A_1$、$C_1$、$A_2$、$C_2$。

\subsection{评价指标与配对统计}

每题使用固定答案比较函数计算正确性 $y_{i,s}^{M}\in\{0,1\}$，其中 $M$ 为模型组，$s$ 为续训种子。主指标先在同一问题上平均两个种子的 C/A 正确性差异，再对全部问题平均：
\begin{align}
  d_i &= \tfrac12\big[(y_{i,1}^{C}-y_{i,1}^{A})
                    +(y_{i,2}^{C}-y_{i,2}^{A})\big],\\
  \widehat\Delta &= \frac{100}{N}\sum_{i=1}^{N}d_i,
  \qquad N=2\,000.
\end{align}
置信区间采用问题配对 bootstrap。以问题为单位有放回抽样 $5\,000$ 次，每次保留该题在两个种子下的全部结果，并计算百分位区间。这样既利用同题配对关系，也保留两个续训种子在相同题集上的关联。统计单位为 $2\,000$ 个问题，区间描述给定检查点下的题目抽样不确定性。

执行指标包括完成率、调用次数和无效调用次数。题目状态划分为未完成、完成错误和正确三类，所有问题均计入准确率分母。配对分析中的“改正”表示 A 错误而 C 正确，“退步”表示 A 正确而 C 错误，两者之差为净增正确题数。

推理成本采用累计 token 指标，计算各轮未填充的完整输入与生成 token 之和，生成部分包含 EOS。历史上下文在后续轮次再次输入时重复计入，用于刻画多轮查询的文本处理开销。硬件运行时间和浮点运算量属于不同的成本维度，本章以统一的 token 统计比较各组推理过程。

\section{执行状态与新增正确答案分析}

\subsection{完成状态转移}

第一个种子净增的 $93$ 道正确题可以拆分为
\begin{equation}
  \Delta N_1=(87-15)+(90-69)=72+21=93,
\end{equation}
第二个种子的对应分解为
\begin{equation}
  \Delta N_2=(87-12)+(84-62)=75+22=97.
\end{equation}
每个式子的第一项为未完成与正确之间的净转移，第二项为双方均完成时错误与正确之间的净转移。两个种子平均净增 $95$ 道正确题，其中 $73.5$ 题来自第一项，$21.5$ 题来自第二项。前者占净增正确题的 $77.37\%$。

全部未完成题均耗尽了 $24$ 次调用预算。因此，从结果分布看，恢复续训的主要可见收益伴随执行完成能力改善，同时也在已经完成的回合中取得正向净收益。上述比例是状态转移计数的算术分解，用于描述收益分布。

状态表还给出两类有助于理解方法行为的现象。第一，两种子分别有 $64$、$68$ 题从未完成转为完成错误，说明提交答案和答案正确是两个不同环节。第二，原本正确的题分别有 $84$、$74$ 题转为失败，表明续训改变了不同问题的生成路径。整体效果由这些改善和退步共同形成。

\subsection{代表性执行案例}

为将状态统计与具体行为联系起来，在每个种子的非空状态格中，除双方正确外，按固定哈希顺序选取一个案例，共得到 $16$ 个案例。以下依据执行器记录、答案状态及模型轨迹进行分析。

\paragraph{从无效循环到正确完成。}
样本 \texttt{train:18006} 在第一种子中由未完成转为正确。A 在取得空结果后反复提交无效句柄，$24$ 次调用中有 $20$ 次无效操作；C 使用关系限定查询，在 $4$ 次调用内正确完成。这个案例体现了两组自由生成路径的差异：有效关系查询使 C 保持可用的中间结果，并避免后续调用不断消耗预算。

\paragraph{合法操作之间的依赖选择。}
样本 \texttt{train:20507} 在第一种子中由完成错误转为正确。两组均使用 $7$ 次调用，且没有无效操作。A 的人物与电影依赖顺序得到空值，C 使用电影到人物的关系方向取得正确角色。该例表明，问答改善还涉及操作方向和依赖选择；这些差异可以发生在全部调用均合法的回合中。

\paragraph{正确路径转为失败。}
样本 \texttt{train:81833} 在第一种子中由正确转为未完成。A 通过正确的出生地关系方向，在 $7$ 步内完成；C 采用反向查询后不断更换关系与句柄，产生 $17$ 次无效调用并耗尽预算。该例显示，早期关系方向的变化可能形成持续失败链条，是恢复训练后仍保留的一类错误。

\paragraph{两组共同保留的困难。}
样本 \texttt{train:31530} 中，两组早期筛选结果均为空，之后没有重建有效目标，各产生 $16$ 次无效调用。样本 \texttt{train:29963} 在第二种子中则表现为职业与工作领域关系混淆，两组均提交了错误答案。这两类失败分别对应目标重建和关系语义选择，说明有效历史利用与问题语义映射共同决定最终问答结果。

这些案例与状态转移表形成互补：状态表量化总体改善及退步，轨迹则呈现空结果、关系方向和依赖选择如何影响后续求解。恢复训练的结果因此可以从最终准确率和执行过程两个层面进行解释。

相对对应的 A，两个 C 的总 token 分别减少约 $8.84\%$ 和 $4.17\%$。这一变化主要来自完整输入累计量下降。分步查询需要逐轮输入已有历史，无效操作形成的长回合会持续增加输入开销。与此同时，生成 token 分别增加约 $3.88\%$ 和 $16.35\%$，其增量低于输入 token 的减少量。两项分开统计能够呈现分步查询中输入开销和输出开销的不同变化。

\subsection{结果奖励驱动的短程强化学习}

为分析结果奖励对监督训练模型的增量作用，从第一种子的 A/C 分别继续开展 GRPO\cite{shao2024deepseekmath}，得到 B/D。训练使用最终答案正确性作为奖励：
\begin{equation}
  r(\tau,q)=\begin{cases}
    1, & \text{提交答案通过比较},\\
    0, & \text{其余情况}.
  \end{cases}
\end{equation}
每个问题采样四条交互轨迹，根据同题轨迹组内的奖励差异计算相对优势，并使用裁剪策略目标更新 LoRA 参数。这样，最终答案奖励通过采样轨迹作用于模型生成的动作序列。

两组各进行 $200$ 次更新，使用相同的 $200$ 道训练题，每题四条轨迹，共 $800$ 条。学习率为 $5\times10^{-6}$，裁剪系数为 $0.2$，KL 系数为零，采样温度为 $1.0$。训练使用 TRL 的原生多轮工具交互实现，完成段上限为 $4\,096$ token，其中包含工具观察，单轮生成上限为 $192$ token。开发评价统一采用表\ref{tab:method-settings}中的原有推理预算。训练记录包含组内非恒定奖励、有效梯度和适配器参数更新。

\section{实验范围与结果解释}

本文公开实验评价的是特定基础模型、知识库执行器及预算下的训练方案。$2\,000$ 题来自官方训练数据中排除历史使用分组的项目留出划分；完全问题和程序去重控制直接重复，题目仍共享知识库中的实体、关系及部分结构。两组随机种子共享初始模型和配对语料，bootstrap 区间对应固定检查点下的问题抽样。A/C 匹配监督 token，恢复历史带来的输入长度变化保留在实际训练中。

在这一范围内，整体训练方案的收益由配对准确率、状态转移和成本记录共同呈现。状态、句柄变化与后缀监督作为完整方案接受评价，各组成部分的独立作用仍需进一步分离。最终答案比较刻画任务成功率，案例和执行记录刻画求解过程；对问题全部限定条件的逐项语义核验属于更细粒度的评价。领域问答还包含知识表示、接口语言和来源条件等因素，下一章使用独立的雷达材料分析这些环节。

\section{本章小结}

本章完成了恢复轨迹监督方法的公开数据评价。两个续训种子的平均准确率由 $78.75\%$ 提升至 $83.50\%$，增加 $4.75$ 个百分点，且两组配对差异均为正。执行分析显示，恢复模型减少了未完成回合及无效调用，相对普通分步续训降低了累计总 token；新增正确题主要伴随执行完成状态改善，双方均完成的回合也取得正向净收益。

不同程序长度与操作类型的分组均获得正向点估计，限定条件查询组表现出较大增益。开发集扩展中，短程 GRPO 和详细报错文本呈现未形成明确的额外收益。综合效果与成本，本文采用恢复轨迹监督作为主要小模型训练方法，并在下一章研究其专业领域适用性，以及雷达知识表示对问答结果的影响。
