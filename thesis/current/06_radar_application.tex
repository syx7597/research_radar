\chapter{雷达领域问答与条件绑定证据评价}
\label{chap:radar-application}

\section{领域问答的研究设计}

雷达资料问答既要求正确执行查询，也要求准确阅读量值及其适用条件。前述公开实验评价恢复轨迹训练对问答准确率与执行表现的影响，本章将训练后的查询模型接入雷达来源知识，并进一步研究检索证据如何进入最终回答。围绕这一过程，设置接口适配、端到端问答和条件绑定表示三个层次的实验。

接口适配考察模型能否按照领域工具签名选择记录；端到端问答考察选定记录所对应的原文能否支持回答；条件绑定对照考察相同语义证据的组织方式如何影响正文和引用。三个层次分别测量记录选择、支持页覆盖、正文正确与引用支持，使结果能够定位到具体环节。

本章沿用公开实验的记号：P 为一次程序生成路线，$A_1,A_2$ 为普通续训路线，$C_1,C_2$ 为恢复轨迹续训路线，下标对应两个续训种子。接入领域工具时，各模型接受相同任务实例构成的接口适配；最终回答则使用统一的 Qwen2.5-3B-Instruct 基础模型。条件绑定实验直接使用该基础模型，比较输入证据的表示方式。

四来源阶段包含 24 道题，用于分析完整问答链路；八来源阶段包含 96 道题，用于表示对照。两批材料的构建过程和参考身份见第三章，以下分别报告实验设置和结果。

\section{直接迁移与共同接口适配}

\subsection{直接迁移的接口表现}

首先在 12 个开发目标上检查五个原始检查点。每个目标提供中英文问题，工具定义和知识库说明保留原有双语或中文内容。评价指标为最终记录集合与目标集合完全一致的数量。

如表\ref{tab:domain-transfer}所示，五个检查点在两种语言下各自仅选对 0--3 个目标。典型失败包括工具参数签名不匹配、条件字段使用错误和未提交结束动作。中英文问题的总正确数相同，但部分成功目标不同。结果表明，已有公开问答训练形成的工具执行能力，还需要通过明确的领域接口样例完成接入。

\subsection{适配语料与训练配置}

共同接口语料由 100 个虚构知识实例组组成，按 60/20/20 分配至训练、开发和保留部分。每组包括中英文问题，对应 120/40/40 条轨迹。实体、知识实例和外层措辞模板按组隔离，属性词、条件标签及短查询结构作为公共接口内容。

四个 A/C 检查点使用相同成功轨迹，每题监督三个助手动作，工具返回内容作为上下文。P 使用相同问题实例的一次程序目标。训练从各自已有 LoRA 继续，固定五轮、学习率 $5\times10^{-5}$、微批量 2、梯度累积 8，共进行 40 次优化更新。每个模型接受 600 次样本呈现；A/C 的实际监督 token 均为 48,670，P 为 21,000。两组 A/C 分别沿用种子 20261003 和 20261004，组内样本顺序一致。

采用共同适配的目的，是让各检查点学习相同领域接口，再观察它们在相同来源问题上的表现。训练内容为成功查询动作，真实制造商题目的答案未用于适配。适配后的参数用于本章实验，前文公开集结果对应适配前的检查点。

\subsection{接口适配结果}

适配后，五个模型在合成保留视图上达到 39--40/40，相较适配前的 0--8/40 明显改善。在开发雷达题上，P 达到每种语言 11/12，四个 Agent 的中文记录选择均为 12/12，英文为 11--12/12。成功轨迹提供的字段、条件与结束动作监督，因而有效完成了当前短程查询接口的适配。

剩余错误涉及 P 的事件选择、$A_1$ 的实体拼写与终止，以及 $C_2$ 的英文条件遗漏。这些现象说明，名称表达、条件传递和任务结束仍是接口调用的具体误差来源。A 与 C 都获得明显改善，为后续使用统一适配方式比较其来源问答表现提供了基础。

本阶段五次训练及前后推理共使用约 0.9160 GPU 小时，按分配设备的任务存续时间计量。合成保留部分用于检验新实例和措辞上的接口使用，开发雷达题用于观察真实字段表达下的变化。真实资料的回答质量由下一节另行评价。

\section{同来源、同回答模型的端到端评价}

\subsection{来源与六条问答路线}

端到端评价采用第三章的四来源材料，包括五个型号、15 个完整 PDF 页、62 条结构化读法和 24 道中文问题。每份资料提供六题，其中八题属于显式查询条件子集。资料保留标量、范围、离散选项与文本等量值形式，并将记录映射到完整原文页。

设置 RAG、P、$A_1$、$C_1$、$A_2$、$C_2$ 六条路线。RAG 通过 BM25 直接检索原文页，参数为 $k_1=1.2,b=0.75$，最多返回四页。中文使用汉字一元和二元切分，并采用固定的通用中英字段扩展。P/A/C 使用适配后的检查点选择记录，再将记录映射到原文页，去重后按固定编号排序，同样最多保留四页。

所有路线使用同一个未经本项目适配的 Qwen2.5-3B-Instruct 作为最终回答模型。输入包含问题、原文页块标题、正文和引用编号；结构化值、中文解释及目标记录编号不进入回答提示。由此，各路线的区别主要体现于证据获取过程，最终阅读与生成配置保持一致。结构化路线额外使用了资料整理和选择器适配，相关成本单独记录。

选择器最多调用 24 次，总生成预算为 2,048 token，逐步 Agent 每轮最多生成 192 token。回答阶段采用批量 8、上下文上限 8,192 token、输出上限 768 token 和贪心解码。实验完成 120 条记录选择轨迹和 144 条最终回答，全部保留用于分项统计。

\subsection{分层评价指标}

为刻画问答链路，采用以下指标。

\begin{enumerate}
 \item \textbf{记录精确选择。} 最终记录集合与目标集合完全相同，衡量查询模型是否定位到目标读法。
 \item \textbf{支持页齐全。} 回答输入包含参考所需的全部原文页，衡量生成模型可获得的证据。完整页可能同时包含多个读法，因此该指标与记录精确选择分别统计。
 \item \textbf{正文正确。} 回答完整表达参考所要求的主体、量值和条件，允许合理的自然语言改写。
 \item \textbf{正文有据与引用支撑。} 分别检查陈述是否得到实际输入证据支持，以及所列引用是否覆盖相应陈述。正文正确、有据且引用支持同时成立时记为联合正确。
 \item \textbf{条件保留。} 在八道显式查询条件题上，检查回答是否保留必要限定。JSON 有效性与严格断言匹配作为输出格式和字段表达的辅助诊断。
\end{enumerate}

语义评价将 144 个输出去重为 58 个唯一答案，由两位隐藏路线标签的 AI 审阅者分别检查。正文正确性的判断一致，五个答案的“正文有据”判断存在分歧，经依据来源复核后统一。该结果采用第三章说明的来源参考与 AI 审阅口径。

根据支持页是否齐全，将正文错误分为证据获取不足和已有支持页仍回答错误两类，结果见表\ref{tab:domain-failure-stage}。四个 Agent 共同失败八题，$C_1$ 另有一道错误；$C_2$ 的八道错误均发生在支持页齐全的情况下。对这些输出的事后阅读归纳出三类专业信息传递问题。

首先是\textbf{量值形式改变}。模型有时将离散脉宽选项表达为连续区间，或把典型工作距离与技术距离合并。其共同特征是保留了部分数字，却改变了这些数字之间的关系。量值类型因此应与数值和单位一起进入证据和答案。

其次是\textbf{条件与配置对应丢失}。在脉宽与 PRF 配置、启动与运行条件、功率与波束限定等情形中，答案可能选到页面中存在的读数，但没有维持题目所要求的条件。完整页包含充分信息，模型仍需正确连接表头、条件与值。

最后是\textbf{主体与描述范围偏移}。扫描器和显示单元的参数混用、器件型号与器件类别回答不完整、发射机与调制器描述混合，均体现了陈述主体或属性范围的变化。引用也需要跟随具体陈述，才能形成可核查的回答。

这些结果给出进一步研究证据表示的依据：当相关页面已经进入上下文时，应显式保存主体、部件、量值类型和条件之间的关系。下一节通过相同语义记录上的表示对照，检验这种组织方式的实际作用。

\section{本章小结}

本章完成了雷达领域的接口适配、端到端问答和条件绑定表示研究。共同成功轨迹使五个模型在合成保留视图上的记录选择达到 39--40/40，并改善了开发雷达目标的接口调用。四来源端到端结果定位出证据阅读与条件表达的瓶颈：$C_2$ 的支持页覆盖为 24/24，而正文正确为 16/24，恢复训练相对普通续训未产生额外回答收益。

针对这一瓶颈，八来源实验在相同语义记录上比较平铺与条件绑定。正文正确从 73/96 提高至 80/96，题级绑定错误从 17 降至 11，输入 token 减少 9.62\%。原始联合正确从 17 提高至 52；事后统一引用解析后，平铺和绑定分别为 55 和 68，显示表示组织和引用处理共同影响最终可追溯回答。公开集训练研究与领域应用研究由此形成具体衔接：前者改善查询执行表现，后者识别专业资料中的信息传递问题，并给出条件绑定证据组织的实验结果。
