\chapter*{摘\quad 要}
\addcontentsline{toc}{chapter}{摘要}

小语言模型在多步知识图谱问答中需要持续处理已经产生的执行状态。动作偏离会改变中间结果及后续依赖，成功轨迹监督对这类历史覆盖较少。本文提出依赖一致的恢复监督方法，利用参考程序构造真实偏离历史上的接续目标。

固定初始模型生成训练题失败回合，保留共同成功前缀及一次参考分歧，通过结果句柄映射和确定性重放连接、核验参考后缀。构造得到418个普通／恢复配对样本，仅监督后续助手动作，两组共享初始化、成功材料及监督预算。

基于Qwen2.5-3B-Instruct与LoRA续训，在KQA Pro的2,000题项目留出集上，两个续训种子的平均准确率由78.75\%提高至83.50\%，增量4.75个百分点，题级配对95\%区间为$[3.53,5.98]$。累计输入与生成token合计分别减少8.84\%和4.17\%。414对可比历史的构造诊断中，全部后缀调用可执行数由原编号拼接的65提高到依赖映射的414。

雷达应用整理八来源502条读法及96题，以AI交叉审阅形成参考。相同语义记录下，条件绑定使正文正确数由73提高至80，参数错绑由17降至11。类型查询接口与来源隔离任务完成参考执行验证，形成有限域内评价基础。

研究建立了恢复目标构造、受控训练与专业资料应用相衔接的流程，为具有参考程序的只读知识查询提供了改善完整求解的方法与实证。

\noindent\textbf{关键词：}知识图谱问答；小语言模型；恢复监督；依赖映射；执行反馈；雷达资料问答

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Small language models encounter divergent histories during multi-step knowledge graph question answering. These histories change intermediate results and dependencies, and receive limited coverage in successful-trajectory training. This thesis proposes dependency-consistent recovery supervision using reference programs to construct continuations for actual divergent histories.

A fixed initial model produces unsuccessful training episodes. A common successful prefix and one reference-divergent action are retained; reference dependencies are mapped to current result handles, and deterministic replay verifies the suffix. The resulting 418 ordinary/recovery pairs supervise subsequent assistant actions while sharing the initialization, successful examples, and supervised-token budget.

Paired LoRA continuation training uses Qwen2.5-3B-Instruct. On a project-held-out set of 2,000 KQA Pro questions, mean accuracy across two continuation seeds increases from 78.75\% to 83.50\%, a gain of 4.75 percentage points with a question-paired 95\% interval of $[3.53,5.98]$. Cumulative input-plus-generated tokens decrease by 8.84\% and 4.17\%, respectively. In a construction diagnostic on 414 comparable historical pairs, all suffix calls execute in 65 direct-splice cases and in all 414 dependency-remapped cases.

The radar application contains 502 source readings and 96 questions from eight source groups, with reference material established through AI cross-review. Given the same semantic records, condition-bound representation increases answer correctness from 73 to 80 and reduces parameter-binding errors from 17 to 11. A typed query interface and source-separated tasks pass reference-execution validation, providing a basis for bounded domain evaluation.

The study links recovery-target construction and controlled training to document applications. It provides a method and empirical evidence for improved solving in read-only knowledge queries with reference programs.

\noindent\textbf{Keywords:} knowledge graph question answering; small language models; recovery supervision; dependency remapping; execution feedback; radar document question answering
