# 错误恢复短论文：相关工作核查与定位

核查日期：2026-11-14。本文档服务于同目录中英文短论文；检索范围为训练分布偏移、恢复轨迹构造、自纠错训练和执行状态诊断。采用论文原文、作者预印本及官方会议记录，详细版本与阅读范围见 `literature_audit.json`。这是定向相关工作核查，并非穷尽性综述或文献方法复现实验。

## 可成立的论文定位

本项目可形成一篇聚焦**可执行知识库问答中恢复监督构造与小模型续训**的实证短论文。研究问题是：学生执行历史偏离参考程序后，如何利用已有程序监督，在当前句柄状态下构造可执行的继续步骤，并把这些步骤转化为小模型的训练数据？方法对象包括只读确定性解释器、追加产生的中间结果句柄，以及已有参考程序。贡献应落在参考依赖与实际执行句柄的映射、后缀重放验证和恢复监督的实证效果上。

已有结果支撑“该训练方案在本项目公开数据留出集上产生了收益”：两个共享初始检查点的续训种子，普通续训 A 平均准确率 78.75%，恢复续训 C 为 83.50%。414 条可比历史样例的 CPU 诊断则说明句柄重映射对于构造有效目标的重要性。这两类证据分别回答端到端效果和目标构造正确性，不能将后者写成模型恢复成功率。题目采样区间的含义、种子范围及实验来源以 `evidence_notes.md` 为准。

## 最接近的方法及区别

下表比较监督来源与构造机制，不比较不同任务上的论文分数，也不把相关论文列为已复现的实验基线。

| 工作 | 状态与监督如何获得 | 如何用于训练 | 本文对应的研究空间 |
|---|---|---|---|
| [DAgger](https://proceedings.mlr.press/v15/ross11a.html)，AISTATS 2011 | 学习策略访问状态，专家为这些状态提供动作标签，迭代聚合数据 | 在聚合数据上重新学习策略 | 本文为一次固定采样后的参考程序构造；不直接继承其迭代理论结论 |
| [Agent-R](https://arxiv.org/html/2501.11425v3)，预印本 v3 | MCTS 得到共享前缀的成功与失败分支，结合修订语句与转折位置构造轨迹 | 迭代自训练修订轨迹 | 轨迹拼接与恢复训练已有先例；本文具体处理解释器中的依赖句柄迁移 |
| [STeP](https://arxiv.org/html/2505.20023v1)，预印本 v1 | 教师检查学生轨迹，生成第一人称反思与纠正动作，收集成功轨迹 | 屏蔽错误思考与动作位置，训练纠正后的示范 | 选择性监督已有先例；本文由已有程序生成目标，不新增教师续写模型 |
| [OEC](https://proceedings.mlr.press/v306/lauffer26a.html)，ICML 2026 | 学生执行到随机交接点，专家接续；环境测试筛选完成任务的轨迹 | 仅对专家部分计算损失 | 本文以参考程序为专家信息载体，着重验证接续时的依赖引用 |
| [ReTerm](https://arxiv.org/html/2610.18484v2)，预印本 v2 | 保存失败终端状态与历史，教师从恢复的环境继续；以多项检查筛选轨迹 | 恢复部分 SFT；另有在线恢复分支 GRPO | 真实失败历史与后缀监督并非本文独有；本文限定到只读程序及显式句柄映射 |
| 本文 | 学生首次参考分歧后的历史、已有 KoPL 程序、当前中间结果状态 | 映射引用、重放验证后缀，仅监督新增助手后缀 | 在明确执行语义下构造并检验恢复目标，提供配对续训结果 |

对 Agent-R 的核查覆盖方法第 3.1–3.2 节；STeP 覆盖第 3.2–3.4 节；OEC 读取正式 ICML 版本第 3.1–3.3 节；ReTerm 读取 v2 第 3.1–3.2 节。STeP 原文支持教师纠正与部分掩码，不据此加入“环境回滚”的描述。OEC 的正式发表年份为 2026，文献键 `lauffer2025oec` 为兼容旧稿保留。

## 训练型自纠错与其他方法

[SCoRe（ICLR 2025）](https://proceedings.iclr.cc/paper_files/paper/2025/file/871ac99fdc5282d0301934d23945ebaa-Paper-Conference.pdf)采用两阶段在线强化学习：先训练第二次作答并约束首次作答分布，再联合训练并奖励纠正进展。它研究数学和代码答案的自纠错，给出了离线纠正训练可能面临分布错配的原因；该结论值得在讨论中联系本文的固定采样设计，不能据此推断本文实验必然需要 RL。

[Fission-GRPO（ACL 2026）](https://aclanthology.org/2026.acl-long.1880/)在在线训练中把工具执行失败转为新的恢复任务，结合错误反馈重新采样纠正分组。其语义错误反馈使用经训练的 Error Simulator，构造过程涉及训练标注工具调用。这是“从真实执行错误训练恢复”的直接近邻；本文的核心问题则是给定参考程序时的目标构造与只读执行一致性。

[Reflexion](https://proceedings.neurips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html)通过语言反馈与记忆指导后续尝试，[Self-Refine](https://proceedings.neurips.cc/paper_files/paper/2023/hash/91edff07232fb1b55a505a9e9f6c0ff3-Abstract-Conference.html)以同一模型完成输出、反馈与修改。两者适合交代推理时修订背景；本文研究参数训练的数据构造。ReAct 用于说明交替动作与观察的交互形式，不把它概括成只有提示工程的方法。

## 对创新表述的直接影响

建议在正文中表达为：**面向具有参考程序和显式中间结果引用的可执行问答任务，构造一种结合句柄重映射与确定性后缀重放的恢复监督方法，并检验其对 3B 模型续训的作用。**

“从错误中学习”“保留学生失败历史”“仅训练纠正部分”“拼接恢复轨迹”都有明确前作。将这些概念单独列为首次创新会削弱论文可信度。本文的清晰贡献来自任务结构、可复查构造机制和已有配对实证的结合。已有参考程序本身也是监督，因此恰当的表述是“构造阶段不调用新的教师续写模型”，而不是“无监督”或“无需专家信息”。

当前最有价值的补强是已经冻结方案的**同状态模型评价**：在相同普通历史与相同分歧历史下比较 A/C 的接续表现，将端到端收益和恢复行为联系起来。现有 CPU 诊断已经解释了构造机制；无需为了凑实验重复扩大这一诊断。若进一步声明部分掩码或某种数据混合比例具有独立因果贡献，则需要对应训练消融，不能用相关工作或构造检查代替。

## 另外筛查的两个候选

- [PALADIN，arXiv:2509.25238 v1](https://arxiv.org/html/2509.25238v1)：方法第 2.2–2.4 节使用工具失败注入、专家恢复标注及推理时恢复样例检索。它与恢复数据训练有关，但本文采用学生参考分歧和既有程序，不采用其故障注入与在线样例检索。仅按预印本记录；未从明确官方录用记录确认会议状态。正文未采用其分数或相对增幅。
- [Executable Prefix Values for Locating Agent Failures，arXiv:2610.17633 v1](https://arxiv.org/html/2610.17633v1)：方法第 3–4 节从可重建执行前缀多次续跑冻结模型，估计剩余预算下成功概率，区分文本上的错误定位和实际可恢复性。其对象是状态诊断，不是恢复目标 SFT。它直接提示本文使用“首次参考分歧”这一操作性定义，避免将其写成经证明的首个语义错误。

这两篇保存在检索审计中；本版主文参考文献控制为 13 项，没有为了扩展列表而加入与主论证关系较弱的条目。
