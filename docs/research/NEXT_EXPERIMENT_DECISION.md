## 1. 决策依据与后验对照

此前用“局部修复只改错2题、beam8改错92题”讨论可靠性时，beam8未得到相同的原查询保护，不能据此确立修复算法的可靠性优势。本次只读既有缓存，补算唯一无参数规则：若beam4的first-valid存在且schema干净，保留它；否则使用beam8的first-valid。选择依据不含金标，之后关联既有逐题正确性计分。

| 方法 | 正确 / 11,797 | 准确率 | 相对beam4纠正 / 改错 |
|---|---:|---:|---:|
| beam4 first-valid | 9,426 | 79.9017% | 基准 |
| v2全局修复 | 9,585 | 81.2495% | 160 / 1 |
| v2局部修复 | 9,602 | 81.3936% | 178 / 2 |
| 普通beam8 | 9,607 | 81.4360% | 273 / 92 |
| 后验：带相同原查询保护的beam8 | 9,643 | 81.7411% | 217 / 0 |

保护规则保留10,371题，其余1,426题使用beam8。新对照比局部修复净多41题。结果见[诊断记录](../../results/condition_consistency/query_repair/guarded_beam8_posthoc.json)。该文件可由原`official_val_metrics.json`的`per_question`复算：对`guard_retained`为真的题取`correct.first_valid`，其余取`correct.beam8_first_valid`；正确性只用于离线计分。另已从原无金标缓存重建保护条件和所选索引，全部11,797题一致。

**这是看过official val后的探索诊断，不是新的独立确认。** 0次改错不是零风险保证；没有实际测量先beam4再按需beam8的在线成本，不能称等预算、更快或成本更低。此诊断不修改或替代旧冻结实验。

当前单字段修复能力有限，不能处理结构、实体、方向或遗漏条件。扩大到多字段、多轮或新模型纠错将形成更大的新方案，而非继续调一个参数。当前证据不足以支持这样的投入。建议结束当前字段修复的开发，将其保留为探索结果与后续对照；不直接进入多种子扩训或雷达迁移。

## 2. 下一轮首选假设

在现有BART生成器上，检验**经执行核验的语义最小负例训练**。保留网络结构，修改训练样本构造，并在普通程序监督训练上加入固定的成对概率约束。目标是提高正确程序被直接生成的概率及候选覆盖率。

对训练问题的金标程序，构造结构相同、参数角色/类型合法、仅一处语义参数不同的错误程序。候选类型从训练侧实际混淆中选择，例如同角色字段、方向或事实限定字段，不事先假定数值比较是主要瓶颈。错误程序须可执行且答案确实不同；同答案样本不自动标错，原始金标疑点要记录。只能使用训练问题和KB构造负例。

旧线性重排探针只在固定候选池中选择，并只得到166对匹配样本；它不能否定生成器训练，但提示必须先检查样本覆盖。若严格对照仍只留下很少样本，先报告不足，不把它当作完整方法实验。

## 3. 已有技术与拟检验的区别

- [SemCL，EMNLP 2022](https://aclanthology.org/2022.emnlp-main.269/)已有语义对比训练、多层负例与生成器训练，不能将“对比学习改善语义解析”称为新发现。
- [PO-KGQA，ACL 2026](https://aclanthology.org/2026.findings-acl.2083/)已有低资源KGQA偏好优化，不能把“执行核验后用错误程序训练”本身称为创新。
- [Candidate Expressions](https://arxiv.org/html/2410.00414v1)已有类型与KB候选约束的生成方法。结构/参数表示及schema约束适合作为强基线参照，不宜未经区别核验就改名为新贡献。

本轮唯一待验增量是：按真实混淆选择的单点语义负例，是否比自然错误和随机合法负例更有效。新颖性和实际收益均尚未成立；若与现有方法实质重合，必须按适配或复现实验陈述。不会同时引入新网络架构、RL和多个新基准。

## 4. 最小实验与继续条件

先做训练侧错误覆盖和样本质量审计，再固定协议。准备四组短时继续训练：

| 组别 | 作用 |
|---|---|
| 仅继续SFT | 排除多训练了一段时间造成的收益 |
| SFT＋自然生成错误负例 | 现成错误反馈训练对照 |
| SFT＋随机同类型合法替换负例 | 排除一般负例增广的收益 |
| SFT＋拟议语义最小负例 | 只检验负例选择的增量 |

后三组使用相同正例问题、损失、负例数量和训练预算；固定模型起点，记录实际token/FLOPs代理计数与耗时。长度、输出类型和空结果比例须匹配或报告，防止再次学到“空结果即错误”。不为每组另选对其有利的训练问题。

推理统一beam4/beam8与相同执行筛选，报告全部自然问题的答案准确率、候选覆盖、纠正/改错和成本，当前修复与带保护beam8保留作参考。参数仅用开发数据选择。official val已多次分析，后续研究须先从未用于训练或模型选择的剩余train组件中冻结新留出集，排除全部既有划分与精确交叠；它须明确称自定义留出集，不能冒称官方test。冻结后只做一次方向验收，不能反复挑集合。

先限定两轮开发调整。若仅超过旧模型，却不超过同预算继续SFT和普通自然负例；或仅在合成错误上改善、自然问题没有增量，则停止该假设。得到小幅但清楚的增量后，才补至三个生成器种子及更完整近邻比较。该门槛不是预设一定成功。

## 5. 雷达联系

雷达参数中的型号、工作模式、阈值及事实条件可能产生局部语义混淆，适合在后续适配中检验。前提是原文与核验图确实保存这些条件；KQA结果不能自动证明雷达单位或区间推理有效。公开自然题的改进成立后，再开展小型核验雷达库与中文接口验证。
