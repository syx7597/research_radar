# 实验前方法论证：研究瓶颈、强基线与开训门槛

> 历史方案，已停止作为当前任务入口。用户明确允许借鉴已有Agent/RL路线，以完成毕业论文为目标；现行方法、文献、对照与预算见[论文主路线](../THESIS_ROUTE_REVIEW.md)。本文的字段约束C和负例假设H保留为审计记录，不再要求先通过H才能开展新主线。

日期：2026-09-26。本文是[论文整体路线](../THESIS_ROUTE_REVIEW.md)的执行细化。方向依据来自已有开发缓存、原文样例和三篇近邻方法；随后完成了C接口、CPU覆盖检查及500题真实生成对照。最新结果见[小试报告](SCHEMA_PILOT_RESULTS.md)。没有新训练或新增官方validation分析。

**决策：研究问题收窄到“自然语言到知识库关系/属性的正确映射”；现有证据不足以把限定符绑定认定为主要瓶颈，也不足以批准新负例训练。先建立已有字段合法性约束生成对照，再判断是否需要针对合法谓词混淆的训练改进。** 这是方法准备顺序，不宣称原创算法已经成立。

## 1. 支撑选择的实际证据

复核原500题开发缓存，使用“保留schema干净的beam4 first-valid，否则采用beam8 first-valid”作为诊断参考，得到404题正确、96题错误。它只是已有缓存上的后验参考；与旧版执行器下400/500的审计不能直接相减归因。

| 96个残余错误的机械观察 | 数量 | 可得结论与限制 |
|---|---:|---|
| 原beam4与beam8候选合集中都没有正确答案 | 78 | 纯重排无法挽回这批固定候选；不等于生成器训练一定有效 |
| 原候选合集中存在正确答案 | 18 | 有选择空间，但不能借金标选候选报成绩 |
| 参考程序与金标函数序列不同 | 37 | 存在结构差异；尚未人工确认全部属于结构错误 |
| 只差一个schema字段 | 21 | 关系12、属性5、限定符2、概念2；不支持只聚焦限定符 |
| 上述单字段原字段本身全局合法 | 11 | 合法性约束不能单独解决全部语义混淆 |
| 任一错误候选距金标只有一个参数差异 | 53 | 金标参考诊断，角色相互重叠，不能称可实现的增益上限 |

21个单字段样例中，`winner/award received`、`follows/followed by`、`participant/participant of`等均显示需要区分关系含义；也有`discontinue/discontinued date`这类非法名称。不能把两种问题合在一起，只与不做合法性约束的弱对照比较。上述数据保留所有题和已知标签疑点，未重新执行金标。

复算入口：[audit_direction_evidence.py](../../scripts/audit_direction_evidence.py)；[结果及逐题差异](../../artifacts/thesis_direction_review/development_evidence.json)。需恢复已记录哈希的开发缓存及官方答案比较模块，再运行`python3 -B scripts/audit_direction_evidence.py --output /tmp/direction_evidence.json`。这里只统计已见开发题，不能外推真实错误比例或用作新效果验证。

全部21个单字段案例已整理成[核查表](../../artifacts/thesis_direction_review/single_field_review.csv)，包含题目、完整预测/金标程序、字段角色和合法性。人工核验列均为pending，没有把机械分类冒充语义金标。数据来源及许可沿用[KQA数据说明](../../experiments/condition_consistency/DATA.md)。

旧负例流水线还有明确问题：2214个接受变体中2010个输出为空；其中2009个变体来自限定字段替换。与自然负例按输出类型/长度匹配后只保留166对。它与当前主要关系/属性差异不对齐。空结果本身不是错误，但这种分布容易让模型学习构造痕迹。来源：[旧配对记录](../../results/condition_consistency/pilot_bart5k_seed20260926/targeted_pairs.summary.json)。

这1000道旧reranker问题后来已分为design/calibration；不能直接把已有166对搬进生成器训练，再把相同calibration当独立校准。未来训练样本必须从正式训练范围另行构造。

## 2. 近邻已做什么

| 近邻（已核验方法章节） | 已有机制 | 本项目不能主张／应如何使用 |
|---|---|---|
| [Candidate Expressions，§4–5](https://arxiv.org/pdf/2410.00414) | 类型语法与分类候选词典树限制KB元素生成 | 字段词表、类型约束及约束解码不是创新；作为强基线来源 |
| [SemCL，§3.1–3.3](https://aclanthology.org/2022.emnlp-main.269.pdf) | 细粒度困难程序采样，按执行结果区分错误与含糊样本，语义对比与监督联合学习 | “执行核验＋困难负例＋对比训练”已有；单点人工扰动只是实现差别，贡献未证实 |
| [PO-KGQA，§3.2–3.4](https://aclanthology.org/2026.findings-acl.2083.pdf) | 模型错误程序的偏好对、DPO＋NLL及KB元素落地 | “执行核验＋偏好训练”已有；普通自然错误训练必须作对照 |

此次没有逐行核验其核心代码或复现论文数值。不同实体链接、训练量与模型配置的文献成绩不能直接与现有5000题BART排名。

## 3. 明确的技术方案与假设边界

固定主干：问题与可用schema → 实体/字段映射 → 可执行计划 → 确定性查询和计算 → 证据回答。研究范围优先考虑关系和属性的语义映射，不加入多轮Agent、RL或大规模数据扩建。

**必须先有的基础对照C：角色字段词表约束生成。** 在现有KoPL表示中识别函数与参数角色，在生成关系、属性或限定字段时只允许对应角色的KB词表；问题金标不进入推理。其目标是排除不存在的字段名，而非判断所有合法字段的语义。实现若只包含字段约束，必须按这个名称报告，不能冒称完整Candidate Expressions复现。沿用原BART和相同候选预算，另记约束开销、意外截断与生成失败。

**唯一保留的训练假设H：在C之上，围绕真实合法谓词混淆选择训练样本，可能比随机合法替换或普通自然错误训练更有效。** 例如相同程序结构中选择错误但合法的关系，并保持其他参数与问题不变。采用已有的成对训练目标即可，拟议增量只能来自有依据的样本选择，不同时发明新网络与新损失。

H不覆盖全部结构、实体和字面值错误，也没有被当前统计证明有效；不能承诺涨幅。若C之后这类错误很少，或H与近邻没有实质区别，就放弃H，不靠扩大作用范围挽救命名。

## 4. 开始训练前必须具备的东西

1. 对已有开发题中的21个单字段样例逐题核查题意、金标及其他候选，区别非法名称、合法含义混淆和标注疑点。AI初筛明确标注，不能假装独立人工评审。
2. 写清C的输入、词表来源、参数边界、失败回退及额外成本；先做不调用模型的约束合法性与覆盖检查。词表只能来自KB，不能从评价金标提取。
3. 为H给出一项可与SemCL/PO-KGQA区分的具体选择规则及必要性；如果只剩“换一种负例”，按消融候选处理，不作为论文创新定题。
4. 核对正式训练范围能提供多少可用正负例，及其空结果、长度、角色和答案类型分布。没有足够且公平匹配的样本时不开始四组训练；不复用已经用于校准的数据训练生成器。

**当前门槛状态：C已完成500题真实对照，非法字段消除，但相对普通beam4只净增1题，95%描述性差异区间跨0，本次实现明显更慢。停止继续调C。** C剩余98题错误中，82题候选池无正确答案；有12例单点合法谓词差异待核查。H的必要性、独立增量和训练样本量仍未过关，不启动GPU训练。详见[实际结果和成本](SCHEMA_PILOT_RESULTS.md)。首批[12条雷达核查记录](../../artifacts/thesis_direction_review/radar_review_batch/README.md)独立待人工复核。

## 5. 通过门槛后的最小实验与停止规则

先固定训练范围、开发次数、报告集和模型起点。已有official val及旧诊断集的使用历史不抹去；新留出范围须在任何新方法比较前一次冻结，不能挑集合追逐收益。

| 对照 | 必须回答的问题 |
|---|---|
| 原BART＋执行筛选，beam4/beam8，以及同保护的扩候选对照 | 收益是否来自更多候选或保守选择 |
| C：相同BART＋字段合法性约束 | 普通合法性约束已解决多少问题 |
| C＋同预算继续SFT | 是否仅是额外训练收益 |
| C＋普通自然错误／随机合法负例，使用相同损失 | 普通错误反馈是否已经足够 |
| C＋H，其他条件相同 | 样本选择是否有独立增量 |

完整自然问题答案准确率为主指标；目标错误子集、候选覆盖与成本作解释，不把人工扰动题的提升替代真实问题结果。开发最多两轮，小试最多四个继续训练臂；具体步数与GPU时长须在开训前写入执行协议，当前尚未分配或使用训练预算。已完成的C推理预算另有账目。若只胜旧模型、不胜同预算SFT/普通负例，或收益仅在合成题出现，停止H。

四臂分别为继续SFT、自然错误负例、随机合法负例、H；自然错误与随机合法替换须独立运行，不能混为一组后遗漏其中一个对照。后三臂使用相同正例问题、成对目标、负例数量和训练预算。

## 6. 如何落到雷达论文

公开集验证同一种映射/计划方法，雷达核验库验证领域适用性；中文解析适配单独报告。领域联系来自真实字段含义、型号与事件归属、单位及有原文依据的条件，不能凭词面把KQA限定符强行对应所有雷达数值。

本轮雷达来源追踪发现一个型号与系统级属性混淆案例，已列为待核验记录，而非金标或已纠正事实。见[雷达标注规范](RADAR_DATA_ANNOTATION.md)。当前最确定的数据工作是保真与来源核验；一例不能证明全库错误比例或推出新的数据算法创新。
