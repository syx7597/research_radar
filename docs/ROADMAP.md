# 六个月执行计划

更新：2026-10-05。电子信息专业硕士，约六个月后提交，无明确创新点数量或发表要求。论文以**可归因的执行反馈学习方法改进**为核心，雷达知识资源、独立评价和系统应用提供支撑；工程规模不能替代核心方法证据。本轮公开训练已经完成，按停止规则保留恢复SFT主方案，不继续扩展RL。完整文献、贡献与七章安排见[论文主线](THESIS_ROUTE_REVIEW.md)，算法细节见[实验子计划](THESIS_AGENT_PILOT_PLAN.md)。

## 1. 本轮公开实验结束，保留恢复SFT主方案

2026-10-04：第二续训种子复现、全量轨迹回放和62条变化案例AI预审完成；两路固定16题RL短测通过后，执行了首种子B/D各200更新、200个相同问题组、800条轨迹及dev500。四个比较复算、1000条B/D轨迹回放全部通过。正式RL训练与dev耗费2.524 GPU小时。四模型错误诊断消融于19:26启动、20:00完成（北京时间），另用1.874 GPU小时，累计15.757/72 GPU小时，没有新训练。

首种子A/C为78.4%/80.8%，第二续训种子77.2%/82.4%；B/D为78.0%/82.0%。D/B差异+4.0个百分点，但RL本身B/A=-0.4、D/C=+1.2个百分点，区间均跨零，且D/C总token增加2.4%。按既有投入标准，停止扩展RL，不追加其种子或奖励搜索；保留恢复SFT作为主方法，RL是有正负结果的辅助对照。见[阶段决定](../results/agent_feedback/rl_stage_decision_v1.json)和[最终复核](../results/agent_feedback/rl_paired_review_v1.json)。

恢复训练的主要观察收益伴随执行稳定性改善，不能直接写成复杂语义推理或因果反馈利用增强。AI预审已标出部分答案匹配但条件遗漏的路径，不能改造成未经核验的训练标签。错误诊断遮蔽后四模型各变化+0.2～+0.4个百分点，区间均含零；C另有5条首次干预前分歧，机制解释进一步受限。原恢复语料仅4/418分歧被工具拒绝，因此不把这个窄探针作为主方法成败门槛。保留原正常反馈，不追加消融或公开训练。领域事实与独立QA核验继续推进，语义核验偏好训练继续暂缓。

五模型留出方案于20:29冻结并在运行前推送仓库；20:37启动，22:44全部生成完成，22:51完成CPU回放与评分（北京时间）。2000题上，A/C首种子78.25%/82.90%，第二续训种子79.25%/84.10%；预先定义的两种子平均增量为+4.75个百分点，按题bootstrap的95%区间[3.53,5.98]。一次性程序P为76.15%。10000条轨迹/程序回放零差异。留出生成实际6.885 GPU小时，项目累计22.641/72 GPU小时。结果支持保留整套恢复训练方法，停止公开基准调参、挑种子和追加训练，转入领域验证。详见[留出分析](../results/agent_feedback/holdout_v1_analysis.json)和[阶段决定](../results/agent_feedback/holdout_stage_decision_v1.json)。

这是项目预留评价，不是官方隐藏测试；两个种子共享初始模型和语料，区间不包含完整训练随机性。C相对A的总推理token减少8.84%/4.17%，但C约为P的23.64/24.72倍，不能宣称整体部署更省或更快。更高答案准确率也不等于所有语义条件都得到保留。

数据、训练配置和原始结果均保留，后续不能挑较好续训种子、把重复开发题合并为独立样本，或把第一种子D与第二种子C作RL效果配对。累计72 GPU小时是上限，不是必须用完的预算。

## 3. 公开方法实验的边界不变

冻结的5,000训练题、500开发题、2,000项目留出题保持不变。一次性程序P是必要强基线；恢复C对普通A检验训练数据增量，B/D按相同终局奖励和预算检验RL。旧BART只作历史参照，不跨模型规模归因。

首轮上限三周、累计72 GPU小时，不是耗时预测或自动预约。开发投入标准：相对匹配对照准确率至少+2个百分点，或下降不超过1个百分点且推理总token减少至少20%；这是决策阈值，不是统计显著性保证。正式实验报告逐题差异区间，并对关键配置补训练种子。

原计划最多一轮有证据的针对性修改；现已完成方法冻结和项目留出验证，不再开启这轮公开方法修改。恢复训练获得正向证据，RL未达继续投入标准；P保留为成本明显较低的基线。接下来完成领域知识与问答实证，不另换任务或奖励体系，不以小规模自建数据涨分替代公共验证。

## 4. 领域评价的最小范围

先覆盖20–30型号及必要的关联对象，200–300条核验事实作为工作量估计，100–150道独立QA作为应用评价起点，按来源质量和题型覆盖调整。现有10,744实体不等于雷达型号数；5,401道自动QA不等于独立人工评价。

对照分四类：同核验事实的扁平/条件化表示；同来源RAG/程序/选定Agent；答案证据支持核查；核验知识与原抽取知识上的误差归因。报告准确率、条件/区间忠实度、支持引用、未知处理、回答覆盖和成本。具体归因限制见[评价矩阵](THESIS_ROUTE_REVIEW.md#52-雷达领域实验先隔离问题再测端到端)。

事实核验与QA独立设计分开；复用旧题做适配训练前，检查完整实体、支持事实与来源重叠，不能只看anchor。论文不要求全库人工重标，不新增抽取模型、多模态学习或装备决策模块。
