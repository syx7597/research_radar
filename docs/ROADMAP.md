更新：2026-10-04。电子信息专业硕士，约六个月后提交，无明确创新点数量或发表要求。论文以**可归因的执行反馈学习方法改进**为核心，雷达知识资源、独立评价和系统应用提供支撑；工程规模不能替代核心方法证据。本轮公开训练已经完成，按停止规则保留恢复SFT主方案，不继续扩展RL。完整文献、贡献与七章安排见[论文主线](THESIS_ROUTE_REVIEW.md)，算法细节见[实验子计划](THESIS_AGENT_PILOT_PLAN.md)。

## 1. 本轮公开实验结束，保留恢复SFT主方案

2026-10-04：第二续训种子复现、全量轨迹回放和62条变化案例AI预审完成；两路固定16题RL短测通过后，执行了首种子B/D各200更新、200个相同问题组、800条轨迹及dev500。四个比较复算、1000条B/D轨迹回放全部通过。正式RL训练与dev耗费2.524 GPU小时。四模型错误诊断消融于19:26启动、20:00完成（北京时间），另用1.874 GPU小时，累计15.757/72 GPU小时，没有新训练。

首种子A/C为78.4%/80.8%，第二续训种子77.2%/82.4%；B/D为78.0%/82.0%。D/B差异+4.0个百分点，但RL本身B/A=-0.4、D/C=+1.2个百分点，区间均跨零，且D/C总token增加2.4%。按既有投入标准，停止扩展RL，不追加其种子或奖励搜索；保留恢复SFT作为主方法，RL是有正负结果的辅助对照。见[阶段决定](../results/agent_feedback/rl_stage_decision_v1.json)和[最终复核](../results/agent_feedback/rl_paired_review_v1.json)。

恢复训练的主要观察收益仍是执行稳定性，不能直接写成复杂语义推理或因果反馈利用增强。AI预审已标出部分答案匹配但条件遗漏的路径，不能改造成未经核验的训练标签。错误诊断遮蔽后四模型各变化+0.2～+0.4个百分点，区间均含零；C另有5条首次干预前分歧，机制解释进一步受限。原恢复语料仅4/418分歧被工具拒绝，因此不把这个窄探针作为主方法成败门槛。保留原正常反馈，不追加消融或训练；冻结P及两续训种子的A/C、主统计和代码，再打开2000题项目留出集。领域事实与独立QA核验并行，语义核验偏好训练继续暂缓。

五模型留出方案已于20:29冻结并在运行前推送仓库；20:37启动四卡A/C推理，之后串接P。下一步检查五路完整性，统一CPU回放后评分；不得按留出结果继续调参或挑种子。当前仅已启动生成，没有留出效果结论。

数据、训练配置和原始结果均保留，后续不能挑较好续训种子、把重复开发题合并为独立样本，或把第一种子D与第二种子C作RL效果配对。累计72 GPU小时是上限，不是必须用完的预算。

## 2. 未来两周：公开实验与领域准备并行

“多知识状态语义核验”仅保留候选论证，不进入当前训练队列。当前工作是收束已验证的恢复SFT方法、完成必要机制诊断与评价冻结，并推进领域独立核验。工程完整性与开发集涨分都不能替代独立验证。

| 优先顺序 | 工作 | 可验收产物 |
|---|---|---|
| 公开训练完成，方法收束 | 有界反馈机制诊断、评价协议与方法冻结 | 区分状态暴露和诊断反馈使用；不循环训练，冻结后再测2000题留出集 |
| 已准备、等待人工事实审阅 | 12条候选的审阅表与12道流程开发题 | 来源绑定全部通过；真人验收仍为0，开发题不得转成最终测试题；见[审阅流程](research/RADAR_REVIEW_WORKFLOW.md) |
| 紧随核验 | 实现最小事实表示与来源依赖 | 一个完整的原文→事实→查询→答案→来源实例，复用旧抽取和执行器，不全库重建 |
| 同步设计 | 独立领域QA与对照协议 | 来源/型号家族划分、3–4个主要题组、同源RAG与执行对照、质量和覆盖指标 |
| 持续写作 | 研究问题、文献、数据章节 | 有出处的研究动机、现状与缺口、方案和评价表；不提前写成功结论 |

首批10–20道人工试标题只用于开发与流程校验，不进入最终独立评价。AI可整理候选与证据，不能代替人类验收。

## 3. 公开方法实验的边界不变

冻结的5,000训练题、500开发题、2,000项目留出题保持不变。一次性程序P是必要强基线；恢复C对普通A检验训练数据增量，B/D按相同终局奖励和预算检验RL。旧BART只作历史参照，不跨模型规模归因。

首轮上限三周、累计72 GPU小时，不是耗时预测或自动预约。开发投入标准：相对匹配对照准确率至少+2个百分点，或下降不超过1个百分点且推理总token减少至少20%；这是决策阈值，不是统计显著性保证。正式实验报告逐题差异区间，并对关键配置补训练种子。

最多一轮有证据的针对性修改，最迟第2个月末冻结模型。恢复无益不声称其创新成立；RL无益采用SFT；P质量与成本占优则采用P。公共开发集已有正向恢复训练证据，独立留出仍未验证，不以小规模自建数据涨分替代。停止追分后，继续完成领域知识与问答实证，不另换任务或奖励体系。

## 4. 领域评价的最小范围

先覆盖20–30型号及必要的关联对象，200–300条核验事实作为工作量估计，100–150道独立QA作为应用评价起点，按来源质量和题型覆盖调整。现有10,744实体不等于雷达型号数；5,401道自动QA不等于独立人工评价。

对照分四类：同核验事实的扁平/条件化表示；同来源RAG/程序/选定Agent；答案证据支持核查；核验知识与原抽取知识上的误差归因。报告准确率、条件/区间忠实度、支持引用、未知处理、回答覆盖和成本。具体归因限制见[评价矩阵](THESIS_ROUTE_REVIEW.md#52-雷达领域实验先隔离问题再测端到端)。

事实核验与QA独立设计分开；复用旧题做适配训练前，检查完整实体、支持事实与来源重叠，不能只看anchor。论文不要求全库人工重标，不新增抽取模型、多模态学习或装备决策模块。
