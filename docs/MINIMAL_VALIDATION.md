# 首轮公开数据最小验证：结果与下一步

2026-09-26。本轮已经完成实际GPU训练、候选执行及对照，不是计划或oracle演示。

**结论：公开实验链路可用；执行合法性筛选有明确收益；当前条件规则和轻量排序器尚未超过有效基线。暂不扩大纯重排或RL投入。**
毕业论文不需要追求SOTA，但仍需超过合理对照，不能把比弱对照好一些直接写成方法有效。

## 实验范围

- KQA Pro原始train内冻结5,000题生成器训练、1,000题排序训练、500题开发诊断。问题/程序精确重复组隔离，不使用official val调参或计分。
- BART-base约140M参数，问题到KoPL程序SFT；10 epoch，790步，学习率5e-5，4卡每卡batch16，有效batch64，BF16，seed=20260926。
- 模型输入仅问题，不提供gold实体、程序、答案或选项。每题beam=4，候选中不插gold；所有对照使用同一候选缓存。
- 官方配套RuleExecutor和答案比较；500题分母完整保留。生成/执行错误计错，合法空答案不自动判错。
- 自然负例与定向负例匹配后各166对，题目和正例完全相同，负例输出类别相同、程序长度差不超过2。两个线性排序器使用相同特征与预算，种子17/29/43。
- 本轮是**开发集预实验**，没有评测完整official val或hidden test。三次排序训练共用一个生成器和候选，不是三个完整系统种子。

数据来源为固定revision第三方镜像，KB/val与已有本地文件字节相同；未能独立取得原作者train压缩包。金标程序6,500题全部可执行，6,498题答案一致；两条原版执行器兼容问题保留原始标签。详见[数据记录](../experiments/condition_consistency/DATA.md)。

## 实测结果

| 方法 | 正确题数 / 500 | 准确率 | 解释 |
|---|---:|---:|---|
| 生成器top1 | 365 | 73.0% | beam排序第一名 |
| 第一个可执行候选 | 400 | **80.0%** | 当前有效基线 |
| 固定条件/词项规则 | 388 | 77.6% | 比有效基线少12题 |
| 普通自然负例线性排序 | 382 / 382 / 383 | 76.4% / 76.4% / 76.6% | 三个排序种子 |
| 条件定向负例线性排序 | 395 / 395 / 395 | 79.0% / 79.0% / 79.0% | 高于上述弱排序对照，仍低于80.0% |
| oracle@4 | 412 | 82.4% | 离线候选上限，不能部署 |

执行筛选相对top1纠正35题、改错0题，+7.0个百分点；按问题配对bootstrap的95%区间为+5.0～+9.2个百分点。执行筛选是已有技术，不能单独主张新颖性。

条件规则相对执行筛选纠正0题、改错12题，−2.4个百分点。定向排序纠正5题、改错10题，净−5题，差值区间−2.6～+0.4个百分点；不能声称提升或等效。

定向排序相对自然排序提高2.4～2.6个百分点，对应配对区间为+0.2～+4.6或+0.4～+5.0个百分点，但这个结论只限于当前低容量线性模型、166对匹配样本及这套开发协议，且更强的执行基线仍领先。不能只选这一组对照作为论文主结论。

限定条件子集122题：执行筛选87题正确、定向排序86题、自然排序88～89题、oracle89题。没有证据称已改善限定条件绑定。

## 最关键的诊断

1. 执行筛选剩余100题错误中，只有12题在当前4个候选内存在正确答案；另88题纯重排无法挽回。限定条件子集的可重排空间仅2题。
2. top1的135题错误中，97题解析/执行失败；其余38题是可执行但答案错误。程序差异分类只能帮助定位，不能等同人工确认的错误原因。
3. 初步规则审计表明，12次额外改错由词项覆盖偏好触发：更接近问题字面的字段名，可能并不是KB真实schema名称。所有规则相对top1的纠正都已经被执行筛选获得。
4. 定向变异容易生成空结果。原始接受的2,214个变体中2,010个为空；匹配后的两组都保留81个空输出与85个非空输出，避免一组单靠空结果获益。仍不能排除其他构造痕迹。

[固定样本错误审计](research/MINIMAL_ERROR_AUDIT.md)记录了前30条top1错题及全部规则改错案例。该审计由AI完成，不是独立人工标注；抽样频率不能外推。还发现题面/金标矛盾和程序碰巧同答案例，公开数据也不等于无噪声。

当前线性特征探针未实现完整的神经事实作用域表示；因此结果否定的是这一首轮简单实现的优势，不能证明所有条件一致性方法无效。但在当前候选空间下，继续直接扩大排序器缺乏足够依据。

## 接下来的最小工作

继续保留公开基准优先的总路线，不重建整个项目。

1. 固定80.0%的执行筛选基线，核查12个可挽回案例和定向排序新增的10个错误，分清条件信号、schema映射和数据噪声。
2. 若确有可观测的条件冲突，最多试一轮**保留生成概率、仅有充分冲突证据时替换**的保守方案，门槛在排序训练集内部确定。对照仍为相同候选预算的执行筛选。
3. 根据候选缺失错误审计，优先考虑值/日期规范化、schema参数映射或受限局部修复；没有证据时不预先包装成新贡献。任何新增候选都需与同预算基线比较。
4. 500题开发结果已被查看，后续方向验证另从剩余train冻结新的留出集，避免反复在本集调参报成绩；最终才评测完整official val。
5. 公开改进成立后再做雷达迁移。参数范围、单位、型号/版本条件与上述表示问题有关，但本轮没有在雷达库训练或评测。
