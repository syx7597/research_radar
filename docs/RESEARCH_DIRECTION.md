# 研究方向：雷达知识构建与复杂约束问答

更新：2026-09-26。用户确认题目可调整、六个月后提交、不必保留强化学习。完整论文范围以[整体路线](THESIS_ROUTE_REVIEW.md)为入口；当前方法准备以[实验前方法论证](research/METHOD_FEASIBILITY_BRIEF.md)为准。

## 1. 稳定主线

建议工作题目：**面向雷达领域的知识构建与复杂约束问答方法研究**。

雷达资料 → 来源可追溯的知识库与文本证据 → 问题的实体/字段映射与可执行计划 → 确定性查询和计算 → 答案与证据。

公开KQA验证方法，独立核验雷达问答验证应用。数据质量、公开方法效果、领域端到端效果分开报告。英文BART是公开基准模型，中文雷达解析与schema适配需要单独完成。

## 2. 当前瓶颈与范围

新的只读开发审计在500题中得到96个残余错误，78题原候选合集中没有正确答案；21题参考程序只差一个schema字段，涉及关系12、属性5、限定符2、概念2；另有37题函数结构不同。这些是金标机械差异，不是独立人工确认的错误原因。

当前优先研究关系/属性的语义映射，不把全部错误归成限定符绑定，也不将数值、结构、实体链接和RL同时纳入一项方法。具体计数与限制见[证据记录](../artifacts/thesis_direction_review/development_evidence.json)。

## 3. 基础方案、候选假设与决定

- **基础方案C：字段合法性约束生成。** 利用KB角色词表约束程序中的字段生成，作为已有机制的对照，不称原创方法或未经复现的论文成绩。
- **候选假设H：真实合法谓词混淆驱动的训练样本选择。** 只有在C之后仍有足够真实混淆、可取得公平训练样本且能说明近邻区别时，才进入最小训练对照。
- **当前不开始H训练。** C的500题对照已完成：相对普通beam4仅净增1题（80.2%→80.4%），未显示可靠收益且明显更慢，停止继续调C。剩余12个单点合法谓词差异仍需核查题意/金标、训练样本覆盖和近邻区别，不能直接当成开训依据。见[实际结果](research/SCHEMA_PILOT_RESULTS.md)。首批12条雷达事实仍独立待审。

困难负例、对比训练、偏好优化及schema约束均有直接近邻。不得把技术名称、常见组件组合或生成后修改阶段的位置变化当成创新证据。详细依据和停止门槛见[方法论证](research/METHOD_FEASIBILITY_BRIEF.md)。

## 4. 数据与论文贡献

现有图谱、文本检索和执行器继续复用；原5,401自动生成QA用于训练/开发资源，不冒充独立人工评价集。原文核验事实表与问答表分离，保留实体归属、数值/单位/区间、事件和原文条件，缺失信息标未知。模板与一个实际待复核样例见[标注规范](research/RADAR_DATA_ANNOTATION.md)。

论文组织为知识资源与任务、可执行问答方法、公开对照、雷达应用和局限。数据构建与系统实现按工程/资源贡献陈述；方法创新必须有独立机制与对照证据，当前尚未确认。

## 5. 历史结果

[首轮排序](MINIMAL_VALIDATION.md)与[查询修复](QUERY_REPAIR_VALIDATION.md)全部正负结果保留。字段修复相对简单扩候选未显示必要性，停止继续开发；后验同保护beam8的81.74%只作已见validation诊断，不宣称新独立验证。

原Agent/SFT/RL开题仍有可复用架构，但当前不要求完成其全部机制；这些小型修复实验既没有证明也没有否定完整RL方案。旧研究方向保存在Git历史，旧开题原文见[proposal.md](research/proposal.md)。
