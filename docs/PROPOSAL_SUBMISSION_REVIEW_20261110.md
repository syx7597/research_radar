# 开题报告提交审阅与方向定稿建议

审阅日期：2026-11-10。审阅对象为11月4日的8页精简版登记表，并对照截至11月8日的实验记录、数据冻结清单和运行准备。审阅者为本轮主助手，未新增模型实验。

## 一、结论：建议保留题目，按统一方向提交

**建议正式题目：《基于执行反馈的小模型知识图谱问答方法研究及雷达领域应用》。**

这个题目覆盖了当前已经确定的研究对象、主要方法和应用场景：以3B量级语言模型进行程序式知识问答，研究真实偏离历史下的恢复轨迹监督，再在雷达条件参数查询中开展应用验证。题目与已有公开实验、来源知识整理和后续域内对照相吻合，适合作为后续六个月工作的固定范围。

判断可继续推进的依据是已有实证和明确的剩余任务：公开项目留出2000题上，普通／恢复续训的两种子平均准确率为78.75%／83.50%；雷达96题中，条件绑定表示的正文正确由73题增至80题、绑定错误由17题降至11题。域内训练、推理和评分入口已实现，训练与评价材料均已冻结。后续核心工作收束为公开同状态评价和雷达域内配对实验。

当前主要执行条件是恢复可用计算环境和核验模型文件。服务器此前重装后暂不可用，本机未找到基础权重及五个原公共检查点的副本。第一阶段先核查原存储与备份；需要配对复现时，沿已保存的数据、配置和评价规则建立新版本。该处理仍属于同一题目下的实验实施。

## 二、固定下来的研究范围

| 层次 | 固定研究内容 | 对应成果 |
|---|---|---|
| 知识与任务 | 雷达主体、部件、量值、条件和出处的关联表示；来源隔离的查询任务 | 来源知识、参考程序、复核与评价材料 |
| 主要方法 | 真实偏离历史、依赖重映射、可执行后缀与选择性监督 | 恢复轨迹构造和参数高效训练方法 |
| 公开验证 | 同起点普通／恢复续训，准确率、完成率、成本及同状态行为 | 公开任务有效性与行为分析 |
| 领域应用 | 条件绑定表示、类型化组合查询、域内普通／恢复配对 | 参数、条件与来源完整性的应用评价 |

后续语料构造细化、来源歧义修订、参数与随机种子设置、计算环境恢复和误差分析，都在这一范围内推进。强化学习扩展保留为已有辅助实验，当前主要训练方法为恢复轨迹监督。

题名和研究对象可以据此稳定下来。具体增益由实际实验测定；研究设计固定的是问题、对照、指标和实施范围。

## 四、实验和结论如何对应

| 实验 | 主要对照 | 状态 | 结论对象 |
|---|---|---|---|
| 公开完整问答 | 普通A与恢复C，同起点、匹配监督量；P作参照 | 已有2000题、两个配对续训种子结果 | 恢复监督对总体问答成功率的增量 |
| 同状态恢复 | A/C从相同正常和偏离历史继续 | 待运行 | 方法对偏离历史的适应情况 |
| 雷达条件表示 | 相同语义记录的平铺与条件绑定 | 已有96题结果 | 条件组织对正文、参数归属与引用支持的作用 |
| 雷达域内训练 | 同一I_domain得到的A_domain与C_domain | 数据与入口已准备，模型实验待做 | 恢复监督在领域查询中的实际增量与成本 |

两个新领域评价部分共享四个来源家族，分别统计24道基础题和12道组合题。开发部分用于方案诊断，最终评价按冻结协议执行。论文将已有公开方法结论、条件表示结论和后续域内训练结果分别对应到证据。

## 五、方法贡献与相关工作的关系

本次重新核对了三项近邻研究的官方论文记录：[Agent-R](https://arxiv.org/abs/2501.11425)、[STeP](https://arxiv.org/abs/2505.20023)、[OEC](https://arxiv.org/abs/2512.14895)。它们分别涉及搜索与轨迹修订、教师纠正与部分掩码、学生历史之后的专家续写。修订稿据此将本课题的具体切入点放在**程序依赖的一致衔接和后缀的执行验证**，通过已有参考程序、结果句柄映射和确定性重放构造训练目标。

这一定义能够对应目前的实际实现与对照实验。论文的方法论证重点是构造规则、可执行条件、训练控制及实测效果；数据与接口工作支撑领域研究的完整性。
