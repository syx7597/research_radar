# 外部开题评价的核对、取舍与对应修订

日期：2026-11-10。依据用户提供的评价、当前开题提交稿以及实际代码与实验记录进行审阅。主助手与两个只读审阅agent分别核对方法实现和研究范围；本轮未修改实验协议、题集、训练代码或启动模型实验。

## 结论

**评价有价值，建议采纳其中加强方法定义、知识表示与证据口径的意见，做一次小幅澄清修订。题目、核心方法和两块待做实验保持。**

这份意见最有帮助的是把讨论集中到“依赖一致、可执行的恢复监督怎样构造和验证”。同时，它对当前实现和已完成实验掌握不全，部分追加实验建议混合了训练方法、推理策略和标签质量三个问题。应逐项核对后取舍。

## 二、需要澄清的几个判断

### 1. 当前映射不会把错误结果直接改名为正确参考结果

公开恢复构造先确认自由执行回合最终答错，再定位与参考工具、参数一致且执行成功的共同前缀。映射只登记这一前缀和重新执行的参考后缀；真实分歧动作及观察保留在历史中，分歧产生的新结果不承担参考步骤的对应关系。每步后缀还要核对执行观察，最后验证参考答案。

依据：[公开恢复构造](../experiments/agent_feedback/recovery.py)、[执行环境](../experiments/agent_feedback/environment.py)、[雷达恢复构造](../experiments/radar_domain/table_recovery_data.py)。

因此，评价提出的“错误Radar B结果被当作Radar A结果”是应防范的设计问题，当前构造已采取对应措施。适用前提和映射规则需要写清。执行观察含摘要或样本，检查结论应表述为依赖、执行及参考答案一致性，不将其命名为独立的通用语义证明器。首次参考分歧也可能是多余但合法的动作，其语义错误性不能仅由路径不同推断。

### 2. 当前A基线比评价描述得更严格

A/C共享普通成功材料、相同参考后缀、监督位置及匹配token预算。配对部分的差异在于：A从共同前缀直接接入后缀，C额外保留一次真实分歧及反馈，再接入映射后的后缀。

“重新生成”属于推理阶段的策略选择；当前主要研究训练样本和监督方式。参考后缀用于离线训练构造，实际评价由模型依据问题和工具观察自由执行。若以后研究重启策略，应单独匹配已经消耗的调用、历史处理及剩余预算，而非把它直接等同于现有A基线。

### 3. 反馈诊断已有结果，但范围较窄

已有推理期诊断保留实际执行状态及全部成功观察，只在调用失败时将具体错误类别与详情替换为通用内容。四个固定模型在dev500上变化为+0.2至+0.4个百分点，四个区间均含零；4000条正常／遮蔽轨迹完成回放。该结果未显示详细错误文字的稳定增益。

它没有覆盖删除全部执行观察或训练期反馈消融，且恢复训练对中仅4/418条分歧被工具拒绝。报告应准确呈现已有诊断，再通过同状态实验分析偏离历史下的求解表现。依据：[反馈诊断结论](../results/agent_feedback/feedback_diagnostic_decision_v1.json)。

### 4. 知识图谱的名称应对应真实实现

公开KoPL任务包含实体关系遍历、属性与限定条件查询、集合运算。雷达已有图投影以23个主体节点连接502个读法节点，关系为`has specification`；部件、条件、量值和出处主要作为读法属性。当前正式域内组合查询使用`Scan/Project/Join/Filter/Derive/Assess`等类型表操作。

因此，可在现有题名下准确说明公开图任务与领域类型视图的联系。评价建议加入国家、制造商、部署等关系网，超出当前被来源核对的核心任务；没有必要为了名称扩建这些关系或更换数据库。依据：[来源图投影](../experiments/radar_domain/kopl_record_bridge.py)、[类型表执行器](../experiments/radar_domain/table_program.py)。

## 三、暂不升级为开题必做项的建议

**“直接拼后缀B”训练消融：** 这一问题值得分析，但直接沿用旧句柄可能产生错误依赖和噪声监督；过滤失败样本又会改变样本选择。同时去掉映射和验证，也难分别识别二者作用。更合适的第一步是有限的构造层诊断：比较构造成功率、依赖失配与参考答案一致率。是否进一步训练消融，应根据该诊断及同状态结果决定，当前未新增实验臂。已有论文B记号还用于RL扩展，后续新增对照需另行命名。

**“增加到3—5个种子”：** 更多复现有价值，但当前两个是共享初始模型与语料的续训种子。增加续训种子仍不覆盖初始训练、语料选择及来源变化的方差。优先完成既定同状态评价与域内配对，保留各种子结果和明确的区间口径。当前不新增3—5种子的刚性承诺。

**“扩充到80—120题”：** 样本覆盖的担忧成立，但这个数值不是由当前来源结构或误差目标推导出的最低要求。原24题和组合12题共享四个来源家族，已有八来源96题则服务于条件表示实验；两类证据需要分别解释。扩写同源问题主要增加题数，来源独立性仍取决于新增家族。先完成冻结评价并报告逐来源结果，再根据明确的外部有效性问题决定一次有界扩展。

**“合成题不能与测试共享任何模板”：** 通用操作、输出格式与任务类型的重合属于待学习能力；需要隔离的是评价事实、答案、近重复问题及来源特定的派生内容。新数据已按来源家族、记录、主体和问题组检查交集，并使用独立完整目录。依据：[冻结复核](../results/radar_domain/frozen_20261107/independent_audit.json)。

外部评价对“毕业支撑足够”的判断可作为积极意见；正式评阅还会考察实际模型结果、分析完整性及学院要求。当前判断的可靠基础是已经保存的实验与可执行研究计划。
