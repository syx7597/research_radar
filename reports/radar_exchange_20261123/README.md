## 页面安排

| 页码 | 标题／用途 | 材料依据 |
|---|---|---|
| 1 | 雷达技术资料的知识组织与可追溯问答 | 参数定位、条件比较、组合核查三类需求 |
| 2 | 让参数与型号、部件和工况保持对应 | 八来源、502条读法、96道问题；条件与来源记录 |
| 3 | 条件关联组织改善资料问答效果 | 正文73→80、错绑17→11；同一引用解析后联合55→68 |
| 4 | 从条件检索到可核查的参数答案 | JRC部件温度案例，参考程序5次调用完成 |
| 5 | 围绕真实资料与典型查询开展有限验证 | 已冻结任务、待开展域内对照与拟交流议题 |
| 6 | 恢复监督的公开方法基础，按需使用 | KQA Pro项目留出2000题，两续训种子均值78.75%→83.50% |

旧PPT的资料构建、可执行查询和研究基础框架可以沿用。新版采用当前实验和数据范围：旧强化学习主线、旧整体图谱规模、173个人工抽样统计、早期模型／Oracle分数及MetaQA计划均未进入交流结论。

第3页属于资料表示对照，第4页属于参考程序执行验证，第6页属于公开基准模型结果，各自标明评价对象。领域恢复模型的新对照仍列后续工作；拟交流议题用于讨论资料表达、查询需求和专家核查，没有预设合作或数据授权。

## 构建

```sh
cache/proposal_env/bin/python reports/radar_exchange_20261123/build_deck.py
python3 reports/radar_exchange_20261123/export_pdf.py
```

数字从现有公开汇总读取并核对。原开题文件和用户修订PDF保持原件，未启动服务器或训练任务。

PDF阅读版采用macOS Quick Look布局与Chromium分页打印，已检查六页；PowerPoint源文件保留可编辑对象。旧PPT提取的空白主题和学校标识保存在assets，演示页中的原始旧内容已移除。
